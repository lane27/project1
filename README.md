# Bonjour.py

Petit projet Python d’exemple qui demande le nom de l’utilisateur et affiche un message de bienvenue. Idéal pour démontrer les notions d’entrée/sortie en Python.

## Fonctionnalités

- Script interactif simple qui demande le nom de l’utilisateur et affiche un message de bienvenue.

## Prérequis

- Python 3.x

## Installation

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/lane27/project1.git
   ```
2. Accédez au dossier :
   ```bash
   cd project1
   ```

(Optionnel) Créer un environnement virtuel :

```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
.venv\Scripts\activate     # Windows
```

## Usage

Exécuter le script principal :

```bash
python bonjour.py
```

### Exemple d’exécution

```
$ python bonjour.py
Bonjour ! Bienvenue dans mon premier projet GitHub.
Comment tu t'appelles ? Alice
Bonjour Alice !
Bienvenue dans project1.
```
