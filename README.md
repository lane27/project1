# Bonjour.py

Petit projet Python d'exemple qui demande le nom de l'utilisateur et affiche un message de bienvenue.

## Description

- Script interactif simple pour démontrer l'entrée/sortie en Python.
- Le programme demande le nom de l'utilisateur puis affiche un message de bienvenue personnalisé.

## Prérequis

- Python 3.x

## Installation

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/lane27/project1.git
   ```
2. Accédez au dossier du projet :
   ```bash
   cd project1
   ```

## Exécution

```bash
python bonjour.py
```
