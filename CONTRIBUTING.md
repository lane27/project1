# Contributing

Bienvenue ! Merci de votre intérêt pour ce projet.

Pour contribuer :

1. Forkez le dépôt et créez une branche :
   git checkout -b feature/ma-amelioration
2. Faites vos modifications, commitez et poussez :
   git push origin feature/ma-amelioration
3. Ouvrez une Pull Request en décrivant clairement votre changement.

Règles rapides :

- Respectez le style Python (PEP8).
- Ajoutez des tests si vous modifiez du code fonctionnel.
- Documentez les nouvelles fonctionnalités dans le README.

Communication :

- Ouvrez une issue pour discuter d’un changement majeur avant de commencer.
- Merci de rester respectueux·se et constructif·ve.
